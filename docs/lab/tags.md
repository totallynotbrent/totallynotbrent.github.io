# Tags

This page carries two tags (`lab`, `demo`). Quartz auto-generates a tag index and a page for each tag, so you can filter the whole garden by topic.

- The tag index is at `/tags`
- Tag pages group every note sharing a tag
- The tags themselves are frontmatter, so they also feed the graph and backlinks
